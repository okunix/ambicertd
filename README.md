# ambicertd

## API 
 
| Действие                                   | Описание                                                                                                                      |
|--------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
| `GET /api/csr`                             | Получить список csr в состоянии ожидания (pending)                                                                            |
| `POST /api/csr`                            | Отправка CSR с токеном на подпись. Производится проверка policy. Если полиси позволяет подписать автоматически то подписываем |
| `GET /api/certs`                           | Получить список выданных сертификатов (для админа - все, для пользователей только его серты)                                  |
| `POST /api/sign/{csr_id}`                  | Подпись сертификата админом                                                                                                   |
| `GET /api/crl`                             | Получение списка отозванных сертификатов                                                                                      |
| `GET /api/revoke`                          | Создание запроса на аннулирование серта                                                                                       |
| `POST /api/login`                          | Получение jwt токена                                                                                                          |
| `POST /api/change-password`                | Простая смена пароля. Нужен jwt токен, старый пароль и новый пароль                                                           |
| `POST /api/signup`                         | Создание нового пользователя (думаю это позволить можно только админу)                                                        |
| `POST /api/policies`                       | Добавление полиси                                                                                                             |
| `DELETE /api/policies`                    | Удаление полиси                                                                                                               |
| `GET /api/policies`                        | Получение всех полиси (админ) и назначеных (обычный пользователь) полиси                                                      |
| `POST /api/policies/{policy_id}/{user_id}`| Назначение полиси                                                                                                             |
